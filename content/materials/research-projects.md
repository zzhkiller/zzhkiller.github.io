# Representative Research and Engineering Projects

# 代表性科研与工程项目

## Professional UAV R&D and Applications for Typical Low-Altitude Scenarios

## 面向典型低空场景的专业化无人机研发与应用

Period: 2025 to 2026.

周期：2025年至2026年。

Role: Core contributor, rank 4/30.

角色：核心贡献者，第4/30位。

Achievement: Developed a professional UAV platform for urban security, emergency communications, perception scheduling, intelligent recognition, and task collaboration. Built a unified scheduling platform for heterogeneous UAVs, supporting collaborative operation across different aircraft types.

成果：面向城市安防、应急通信、感知调度、智能识别和任务协同研发专业化无人机平台，建立异构无人机统一调度平台，支持不同类型飞行器协同作业。

Technical focus: target detection, behavior recognition, intelligent scheduling algorithms, multi-mode navigation, anti-interference control, and real-time response in complex low-altitude environments.

技术重点：目标检测、行为识别、智能调度算法、多模态导航、抗干扰控制和复杂低空环境下的实时响应。

## Data-Driven Code Assembly Platform

## 基于数据驱动的代码组装平台

Period: 2023 to 2025.

周期：2023年至2025年。

Role: Project lead, rank 1/40.

角色：项目负责人，第1/40位。

Achievement: Led an automated code assembly platform based on data-driven reuse, component reuse, modular code repositories, and knowledge graphs. The platform supports rapid component matching and intelligent assembly.

成果：主持建设以数据复用、组件复用、模块化代码仓库和知识图谱为基础的自动化代码组装平台，支持快速组件匹配与智能组装。

Reported outcome: the platform improved average R&D efficiency by more than 30% according to the personal statement.

成果表现：据个人陈述，平台使平均研发效率提升30%以上。

周期：2025年至2026年。

角色：架构负责人。
